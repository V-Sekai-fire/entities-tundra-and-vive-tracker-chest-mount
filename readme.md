# entities-tundra-and-vive-tracker-chest-mount

Printable models for a chest mount that holds a body-tracking puck on a camera chest harness, from two community designs.

## What it is for

Each folder holds one designer's printable meshes, the CAD sources where the designer shared them, and a saved copy of the design page.

## Build and run

Print the meshes from one folder, then fit them with a tracker to a camera chest harness.
